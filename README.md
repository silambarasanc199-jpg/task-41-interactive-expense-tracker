# ExpenseFlow — Interactive Expense Tracker

A responsive Interactive Expense Tracker developed as part of the Veda Technology Web Development Internship — Task 41.

## 📌 Project Overview

ExpenseFlow is a client-side expense management web application that allows users to add, manage, search, filter, sort, and analyse their personal expenses directly in the browser.

All expense data is stored locally using the browser's LocalStorage. No demo or hardcoded expense records are used.

## 🎯 Objective

The main objectives of this project are:

- Practice JavaScript DOM manipulation
- Work with arrays and objects
- Implement event handling
- Manage form data
- Perform CRUD operations
- Use LocalStorage for data persistence
- Implement search and filtering
- Implement sorting
- Create dynamic UI updates
- Build a responsive web interface

## ✨ Features

- Add new expenses
- Edit existing expenses
- Delete expenses
- Delete confirmation
- LocalStorage data persistence
- Search expenses
- Filter by category
- Filter by date
- Sort by newest date
- Sort by oldest date
- Sort by amount
- Sort alphabetically
- Total spending calculation
- Visible expense count
- Category count
- Category-wise spending summary
- Form validation
- INR currency formatting
- Responsive desktop, tablet and mobile UI
- Empty-state handling
- Keyboard Escape support
